# ⏱️ Samaya (समय)

A simple and modern **Pomodoro Timer web app** built using HTML, CSS, and JavaScript.  
Samaya helps you stay focused, manage your time, and improve productivity using the Pomodoro technique.

---

## 🚀 Features

- ⏱️ 25/5 Pomodoro Timer (Focus & Break mode)
- ▶️ Start, Pause, and Reset controls
- 🔥 Streak counter to track productivity
- 🎵 Simple music support (upload and play your own audio)
- 🔔 Sound alert when session ends
- 🎨 Clean and modern UI design
- 📱 Fully responsive (works on mobile & desktop)

---

## 💡 About

**Samaya (समय)** means *Time*.  
This project is designed to help users manage their time effectively and stay focused while studying or coding.

---

## 🛠️ Built With

- HTML
- CSS
- JavaScript (Vanilla)

---

## 📦 How to Use

1. Download or clone this repository
2. Open `index.html` in your browser
3. Click **Start** and begin your focus session
4. Upload music if you want background focus sound 🎧
